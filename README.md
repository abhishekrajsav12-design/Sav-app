SAV FAMILY

One Family, One Community

SAV FAMILY is a digital platform designed for the Simultala Awasiya Vidyalaya (SAV) community. It aims to connect students, teachers, parents, alumni and school staff through a unified application.

Features

- Role-based access for different members of the school.
- Student registration and verification.
- Teacher and parent communication.
- School notices and announcements.
- Attendance management.
- Homework management.
- Alumni community.
- User profiles and approval system.

User Roles

- Principal
- Vice Principal
- Teacher
- Parent
- Student
- Alumni
- Other Staff Member
- Non-Teaching Staff

Technology

- Android
- Kotlin
- Firebase
- Google AI Studio

Project

SAV FAMILY is being developed to make school communication, information sharing and management easier within the SAV community.
